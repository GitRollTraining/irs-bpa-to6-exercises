## What the quoted rules hold

The guide and the check quote these lines as the notebook has them. This list gives each finding inside them.

- "Revise by editing the prompt, then re-score the whole set." is a heading of day 2, section 2.2. It holds two instructions: revise the prompt, and score the set again. The guide and the check name it only as the place of the two list items below it.
- "A loop: run the set, score it, edit the prompt" is a list item below that heading. It holds three instructions, one for each step of the loop.
- "Then run the whole set again, and compare" is a list item below that heading. It holds two instructions: run the set, and compare the scores.
- "Start by looking, not by measuring." and "Score the fields, not the note" each hold one instruction and the thing not to do.
- "Each note beside its JSON and the JSON it should be" is a list item below "Start by looking, not by measuring." It has no verb. It names what to look at: each note, its reply and its label.
